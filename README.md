#  Student Registration System

##  Project Overview

The **Student Registration System** is a responsive web application that allows users to manage student records efficiently. Users can add, edit, and delete student details, and the data is stored in the browser using Local Storage so it persists even after refreshing the page.

---

## Features

*  Add new student records
*  Edit existing student details
*  Delete student records
*  Data persistence using Local Storage
*  Fully responsive design (Mobile, Tablet, Desktop)
*  Dual view system:

  * Desktop → Table view
  * Mobile → Card view
  * Input validation:

  * Name → Only characters
  * Student ID → Only numbers
  * Contact Number → Minimum 10 digits
  * Email → Valid email format
  *  Prevents empty submissions
  *  Scrollable records section

---

##  Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive design
* **JavaScript (ES6)** – Functionality and logic
* **Local Storage API** – Data persistence

---

##  Functionalities Explained

###  Add Student

Users can enter student details in the form and click **Add Student** to store the record.

###  Edit Student

Clicking the **Edit** button loads the data into the form and changes the button to **Update Student**.

###  Delete Student

Users can remove a student record permanently using the **Delete** button.

###  Data Persistence

All records are saved in **Local Storage**, ensuring data is not lost on page refresh.

---

##  Responsive Design

The application is fully responsive:

* **Mobile (≤ 640px):** Card layout for better readability
* **Tablet (641px–1024px):** Stacked layout
* **Desktop (≥ 1025px):** Side-by-side layout (Form + Table)
